# InstrSnapConfig — 仪器配置快照工具

保存 / 加载 / 一键恢复泰克 5 系示波器（MSO54/56/58）配置的桌面小工具。
重复实验不再重复调仪器面板——保存一次，以后一键恢复。

## 功能

- **一键保存配置**：把示波器当前的全部常用设置（各通道垂直、水平、触发、采集，共 21+N 项）读出并存为 `.json` 文件（中文键、可用记事本直接查看/手工微调）
- **加载配置文件**：选择历史保存的 json，界面树形预览每个参数
- **应用配置到仪器**：把 json 内容逐条写入示波器并回读校验，恢复到保存时的状态
- **按需选择恢复参数**：应用前弹出勾选窗口，可去掉不想恢复的参数；带宽限制等探头相关项默认不勾选（换探头后可设范围不同）
- **扫描仪器**：点**扫描**自动查找局域网内的仪器并填入 IP，无需在示波器屏幕上查地址（多台时弹出选择列表；找不到时可在示波器 Utility → I/O 里核对 IP 后手动输入）

## 环境要求

- Windows + Python 3.10 及以上（https://www.python.org/downloads/ 安装时勾选 Add to PATH）
- 示波器与电脑在同一局域网（网线直连或同交换机）

## 安装与运行

两种方式任选：

**方式一：免安装 exe（推荐普通使用）**

从本仓库 **Releases** 页下载 `InstrSnapConfig_V0.1.exe`，双击运行，无需安装 Python 和任何依赖。

**方式二：源码运行（推荐开发调试）**

```bash
pip install -r requirements.txt
python main.py
```

无需安装 NI-VISA 驱动（使用 pyvisa-py 纯 Python 后端；若本机已装 NI-VISA 也可正常使用）。

## 使用步骤

1. 启动本工具，仪器选"示波器 - 泰克 5 系 (MSO54/56/58)"，点**扫描**自动查找并填入仪器 IP（也可手动输入，如 192.168.1.20），点**连接**——设备 ID 栏显示 TEKTRONIX,MSO5x… 即成功
2. 在示波器上把配置调到你想要的状态
3. 点**一键保存配置**，选保存位置（默认文件名：型号_日期_时间.json）
4. 下次实验时：连接仪器 → 点**加载配置文件**选当时的 json → 点**应用配置到仪器** → 在弹窗中勾选要恢复的参数（默认全选，带宽限制不选）→ 点**确定**
5. 弹出汇总"共 N 项：成功 X，失败 Y，回读不一致 Z"——全绿即恢复完成

## 常见问题

- **连接失败**：检查网线/ping IP/确认示波器 LAN 设置里 "VISA over LAN"（Socket Server）已启用
- **扫描不到仪器**：确认示波器与电脑在同一局域网且 LAN 的 VXI-11/仪器通信已启用；直连网线时首次扫描可能需要等几秒；仍不行可在示波器 Utility → I/O 里查到 IP 后手动输入
- **回读不一致（橙色提示）**：应用后逐项回读比对，只有值真正不同才提示。仪器响应格式状态（VERBose 长短格式）与保存时不同导致的缩写差异（`EDG` 与 `EDGE`）或数值格式差异（`1.0` 与 `1.0000E+00`）视为**等价、计入成功**，日志区以 `[等价]` 行说明；水平模式为 AUTO 时记录长度由仪器自动调整属正常现象
- **个别参数保存失败**：不同固件版本支持的命令略有差异，看日志区定位是哪条命令
- **换机器应用配置**：探头衰减是只读参数（由物理接入的探头决定），不参与恢复
- **带宽限制默认不恢复**：带宽上限受物理接入的探头制约（换探头后如 250→200 MHz），恢复保存值必然不一致，故参数选择窗口中默认不勾选；用同一探头想恢复时手动勾上即可

## 配置文件格式

保存的 json 为中文键字典，顶层含 仪器类型/型号/IDN/IP/保存时间，"示波器" 下按 "1通道参数"…"N通道参数"、"水平"、"触发"、"采集" 分组。可以手工编辑（改完保存仍为 UTF-8 即可）。

## 已知限制

- 仅支持泰克 5 系示波器（信号发生器、源表等在开发中，下拉列表可见）
- 应用配置不清除表外设置；如需完全复位请先在示波器上 Default Setup
- 仪器失联时单条命令最长等待 10 秒，应用过程中请勿断网

## 开发

```bash
python -m pytest tests/ -v   # 全部 57 个测试（无需真机，mock 测试）
python -m PyInstaller --noconfirm --onefile --windowed --name InstrSnapConfig_V0.1 \
    --collect-all pyvisa --collect-all pyvisa_py main_v0.1.py   # 打包 exe 到 dist/
```

入口说明：`main.py` 为持续更新的主入口；`main_v0.1.py` 为 V0.1 发布版本的固化入口（两者逻辑一致），打包发布用后者。

架构：core/（json 存取）、instruments/（pyvisa 驱动 + 白名单命令表 + 扫描发现）、gui/（Tkinter 界面）。设计与计划文档见 docs/superpowers/。
